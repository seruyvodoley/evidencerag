# Состояние проекта — 31.10.2026

**Публичный пользовательский MVP работает:** https://osnovanie.91-196-32-58.sslip.io . Production release 20261031-004, существующий VPS serv.host, собственный systemd backend на localhost, согласованный маршрут существующего Caddy. Внешний HTTPS и 8 браузерных сценариев проверены. Это исследовательский прототип, а не завершённая научная платформа.

Работают PDF/DOCX/TXT/MD, извлечение/индекс, точное происхождение, приватные временные пространства, upload/delete, русский FTS/BM25, выбор версии/даты, текстовый diff и сигналы полей, пять демонаборов, offline-baseline/абляции и CSV/JSON. Один демовопрос поддерживает формальный вывод; остальные ответы показывают исходные выдержки и ограничения.

Проверки: 32 unit/integration; 8 E2E локально и 8 на публичном сайте; 17 VPS-smoke; production build/check. Резервная копия proxy создана, реальный откат приложения протестирован. Основные VPN/Xray InvocationID/статусы, маршруты, firewall и Docker networks совпали до/после. Не подтверждается end-to-end трафик всех VPN-клиентов.

Исследование: проверены обязательные исходные публикации и близкие VersionRAG/TimelyRAG/Self-RAG/DRAGIN/ALCE. У ACM доступна аннотация, direct DOI дал 403. Новизна не установлена. S2G-RAG не запущен; причины и способ подготовки описаны в S2G_BASELINE.md.

Актуальные эксперименты: experiments/run-003. 21 test-вопрос × 8 конфигураций. Evidence recall=1 у четырёх baseline на размеченных случаях; F1 формальных сигналов 0.909, False Abstention=1. Размер контекста отличается; преимущества предложенной стратегии не показано. Faithfulness отсутствует, Unsupported Answer Rate при отсутствии ответов null. Не называть эти числа результатом полноценной научной валидации.

Ограничения: нет OCR, embeddings и семантического судьи; нет независимого большого корпуса/двойной разметки, данных достаточно только для fixtures. Текущий бюджет LLM — выключен, публичного endpoint нет. UI не даёт редактировать метаданные уже загруженного файла (можно удалить и загрузить снова). Исходники на русском UI без готовой английской локализации. Rate bucket за proxy общий, нужен следующий этап масштабирования. SSLIP — временная внешняя DNS-зависимость.

Все дальнейшие изменения VPS должны сохранять ограничения TunnelDeck. Разрешение владельца относилось к этому конкретному HTTPS-маршруту; оно не является разрешением изменять VPN или чужие службы.

## Обновление навигации и значка

Страницы имеют собственные адреса `/`, `/documents`, `/compare`, `/method`. Семантические ссылки поддерживают Ctrl/Cmd-click и контекстное открытие в новой вкладке; History API и popstate обеспечивают Назад/Вперёд, восстановление прокрутки и сохранение форм/результатов между разделами. Backend отдаёт HTML для прямых адресов и обновления. Активный пункт имеет aria-current, после перехода фокус переносится в main. Favicon создан из собственного векторного знака: SVG, PNG, ICO и apple-touch-icon; внешних изображений нет. Production release 20261031-004.
