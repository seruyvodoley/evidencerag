# VPS и TunnelDeck — этап 008

У указанного владельцем VPS SSH endpoint порт 22 из текущего окружения не ответил в пределах `ConnectTimeout=6`; read-only попытка завершилась timeout. Состояние системных сервисов, дисков, Docker, Caddy, firewall и TunnelDeck этим не установлено. Изменений на VPS в этом этапе нет.

Пользователь ранее сообщил, что самостоятельно отключил приложение VPS. Это сообщение не подтверждает, какой unit/container был остановлен и что TunnelDeck продолжает работать. Проверить TunnelDeck также не удалось. Никакие команды остановки, удаления, очистки БД/backup, настройки Caddy, firewall, маршрутов, VPN или Docker не выполнялись.

Безопасный критерий завершения: после успешной публикации статики и публичной приемки выполнить read-only SSH инвентаризацию с закреплённым host key; установить точное имя только EvidenceRAG unit и его зависимости; снять baseline TunnelDeck; остановить только EvidenceRAG unit обратимым `systemctl stop`, проверить VPN health/connected clients и Caddy routes, сохранить backup; не выполнять `disable`, purge, очистку volumes или удаления данных без отдельного явного согласования. Если VPS вновь недоступен — оставить статус как блокер и не выдавать отключение за подтверждённое.
