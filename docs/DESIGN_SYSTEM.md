# Дизайн «Основания»

Рассмотрены три концепции до реализации:

1. «Цифровой архив»: белые листы, чернильный текст, узкая навигация, связанные цитаты и редакции. Легко начать обычному пользователю; пригодно для длинного чтения и исследования.
2. «Картотека»: насыщенный зелёный фон, светлые вкладки документов, крупные индексы. Выразительно, но цветные поверхности и вкладки мешают чтению на телефоне.
3. «Оптическая лаборатория»: тёмная сетка, временная шкала версий, яркие сигналы. Уместно для исследовательского стенда, но сложнее неподготовленному пользователю и для длинных документов.

Выбрана первая: основная задача — сопоставлять вопрос и первоисточники. Отвергнута изначальная идея газетной сетки с обилием линеек: это декоративная строгость, не помогающая поиску. Визуальный акцент — парные листы разных редакций, где выделены конкретные изменившиеся поля.

Палитра: бумага #ffffff; фон #f2f5f7; чернила #182c3d; вторичный текст #526474; источник #176654; предупреждение #875218; разделитель #d9e2e8. Без градиентов, стоковых изображений, фальшивых чисел и декоративных графиков.

Типографика: Georgia для названия и основного заголовка; системный sans-serif для интерфейса и источников. Локальные системные шрифты, без внешних запросов. Иерархия 56/36/24/18/16/14 px; на телефоне заголовок 38 px. Обычный текст не уже 16 px, строки источников до 78 знаков.

Композиция: главная — объяснение слева, содержательное сравнение справа; ниже галерея доступных корпусов. Рабочая область — список документов слева и вопрос с источниками справа; выбранный источник раскрывается отдельным листом. На телефоне всё в один поток. Выравнивание влево. Радиусы 4–14 px по роли. Минимальные интерактивные цели 44 px.

Доступность: семантические кнопки и ссылки, skip-link, явные подписи, focus-visible, статус aria-live, текстовое объяснение цвета, native dialog, отсутствие автоматических анимаций. Проверка по frontend-design и web-design-guidelines.

Знак вкладки: кодовый SVG с белой скобочной буквой A на #176654, без зависимости от шрифта. Растровые размеры 16/32/180 и ICO генерируются scripts/create_icons.py из той же геометрии. Навигация между разделами без декоративной анимации, с URL, active state и корректным фокусом.

## Stage 009 — ответ и цепочка доказательств

Короткий проверенный ответ занимает первое место в результатах: белый лист, исходная архивная палитра, зелёная боковая граница `#176654`. Список фактов и их даты отделяются тонкими линиями; на узком экране факт и переход к цитате располагаются вертикально. Пропуск и конфликт используют уже существующий янтарный тон `#875218`. Новая цветовая система и декоративные карточки не добавляются: визуальный акцент — сам ответ, а не метрики или статусные бейджи.
