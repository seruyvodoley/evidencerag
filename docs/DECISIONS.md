# Принятые решения

31.10.2026:

- Svelte/Vite static + FastAPI вместо двух SSR-процессов: меньше RAM и проще единый origin.
- SQLite FTS5 вместо vector DB: CPU-only, воспроизводимость и отсутствие API-ключей. Русская морфология улучшает совпадения форм слов, но не делает поиск семантическим.
- BLOB originals вместе с chunks: атомарное удаление и строгая область workspace. Лимит 40 МБ/пространство сохраняет масштаб разумным.
- Короткоживущий bearer-cookie вместо аккаунтов: мгновенное демо, минимум персональных данных. Потерянное cookie нельзя восстановить.
- Не скрывать конфликт автоматическим выбором последней версии: без даты показать разные редакции; по дате — явно объяснённый фильтр полных снимков.
- Формальные подтверждения только для авторских правил. Документы не могут объявлять себя «доказанными» или задавать код/инструкции.
- Простой key:value detector и текстовый diff без заявления о семантической проверке.
- S2G-RAG не воспроизводить на VPS: официальный launcher содержит CUDA/обучение; сравнительный запуск переносится на отдельные ресурсы.
- Исследовательский run-001 не подтверждает превосходство. Сохранены отрицательные результаты, пустые метрики как null.
- Предпочесть отдельный systemd-сервис с localhost вместо Docker: на этом VPS так не добавляются сети/iptables правила. Shared Caddy отдельно, только после согласования маршрута.
- Sites изучен, но его cloud-hosting не использован: пользователь явно задал Python/SQLite и существующий VPS. Развёртывание в другой инфраструктуре не подменяет это требование.
