# Измерения производительности

Дата: 31.10.2026. Конфигурация: один Uvicorn worker, SQLite FTS5, pymorphy3, десять коротких демодокументов в каталоге. Числа ниже не являются обещанием максимальной посещаемости.

## Локальный smoke-load

scripts/load_test.py: 40 настоящих HTTP-поисков по двум редакциям «Север», параллельность 4, прогретый процесс на компьютере разработчика Mac. Успешно 40/40, все HTTP 200. Общая длительность 0.415 с, 96.35 запросов/с в этом коротком прогоне. P50 37.36 мс, P95 61.46 мс. Сырые времена — experiments/local-load.json.

Это маленький корпус и короткий burst: steady-state, большие индексы, холодный парсер, множество клиентов, ошибки диска и файлы предельного размера не измерены. Браузерные тесты могли конкурировать за ресурсы Mac. Эти показатели нельзя переносить на 1-vCPU VPS.

## VPS

scripts/vps_smoke.py выполняет пять последовательных реальных поисков; отдельные измерения — experiments/vps-smoke-final.json. Первый smoke дал median 3.84 мс loopback и около 62 MiB MemoryCurrent после операций. Это проверка пригодности маленького pilot, не нагрузочный тест. Публичный HTTPS E2E включает сетевые задержки и TLS, но не является latency benchmark.

## Заданные пределы

Production: 8 одновременных HTTP-соединений, 1 parser, 15 секунд wall-time парсера, Linux 12 секунд CPU/384 MiB AS, 640 MiB cgroup MemoryMax, 60% одного CPU, 64 tasks. Поиск ограничен 3 итерациями/20 выбранными фрагментами/500 мс по умолчанию. SQL progress handler и 50 мс busy timeout дают предсказуемое прерывание, но бюджет кооперативный и имеет overhead.

Frontend: production JS около 73.9 kB / 27.1 kB gzip; CSS около 20.2 kB / 4.8 kB gzip. Внешних шрифтов/изображений/CDN нет, Svelte dev runtime на сервере не запускается. Оригиналы не рассылаются внешней модели.

Для расширения pilot нужны длинный локальный тест с разными corpus sizes и наблюдением RSS, учёт дискового overhead FTS, лимит свободного места, rate limiting с проверенным proxy trust и очередь парсинга. Не увеличивать пределы на VPN-VPS без новых измерений. Сейчас 90 мутаций/минуту за общим proxy делятся между всеми посетителями.
