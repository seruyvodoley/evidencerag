# Бесплатный читаемый адрес — подключён 31.10.2026

Основной адрес: https://osnovanie.duckdns.org . Домен добавлен в аккаунт Duck DNS владельца после его самостоятельного GitHub-входа и прохождения CAPTCHA. Запись подтверждённо указывает на предоставленный владельцем IP VPS. Это бесплатный поддомен стороннего DNS-сервиса, не купленный собственный домен.

Пароли и DNS token не запрашивались в чате, не экспортировались из браузера и не сохранялись в репозитории или на VPS. Для регистрации использована UI-форма. При попытке указать VPS-IP сервис сообщил, что запись уже имеет это значение; DNS дополнительно проверен с компьютера разработчика и с VPS.

Новый hostname добавлен только к собственному site-блоку EvidenceRAG в существующем Caddy. Старое имя osnovanie.91-196-32-58.sslip.io сохранено. Перед изменением проверен hash текущего Caddyfile, создан root-only backup /opt/evidencerag/proxy-proposal/Caddyfile.before-duckdns, candidate прошёл caddy validate, выполнен graceful reload. Bind, VPN, DNS сервера, firewall и Docker networks не менялись.

HTTPS проверен внешним клиентом без отключения проверки сертификата; главная и /api/health возвращают HTTP 200 с реальным содержимым. Проверки — experiments/duckdns-deployment.json и duckdns-public-availability.json. E2E по новому адресу — experiments/e2e-results.json; предыдущая проверка старого имени — e2e-sslip-results.json.

Cookies привязаны к hostname: существующие документы старого имени доступны по старому адресу, а на новом создаётся отдельный сеанс. Принудительный redirect старого hostname не включён. Относительные переходы работают на обоих именах.

При фиксированном VPS-IP cron или DNS-update daemon не нужны и не добавлялись. При смене VPS-IP запись обновляется в аккаунте владельца. Официальный сервис: https://www.duckdns.org/ .
