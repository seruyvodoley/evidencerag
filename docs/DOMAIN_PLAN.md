# Короткий бесплатный адрес — состояние 31.10.2026

Владелец выбрал бесплатный поддомен вместо покупки собственного домена. Текущий сайт продолжает работать: https://osnovanie.91-196-32-58.sslip.io . Настроены отдельные маршруты страниц и branded favicon, production release 20261031-004.

Для читаемого управляемого имени выбран Duck DNS. Предпочтительное имя `osnovanie.duckdns.org`; его доступность пока не подтверждена. Альтернатива при занятости — `evidencerag.duckdns.org`. Эти имена ещё не зарегистрированы и не объявляются адресами работающего сайта.

Duck DNS требует входа владельца через Google/GitHub. В in-app браузере открыта вкладка https://www.duckdns.org/ и оставлена для пользовательского входа. Пароли, токены и OAuth-разрешения агент не вводил и не принимал. Владелец получил просьбу войти и написать «Готово». До этого изменения DNS не выполнялись.

После входа:

1. Проверить свободное имя и создать запись на публичный IP VPS, уже предоставленный владельцем. Не использовать чужую занятую запись и не менять существующие записи аккаунта.
2. Не сохранять и не печатать Duck DNS token. Dashboard может показывать token открытым текстом: для наблюдения UI использовать подавление автоматического вывода и редактирование токенов/email в выводе. Предпочесть UI-форму DNS-записи, не экспортировать credentials.
3. Проверить фактическое DNS-разрешение. Для статичного IP не нужен cron с секретным token на VPS.
4. Сохранить действующий Caddyfile, проверить отсутствие чужих параллельных изменений, добавить новый hostname к собственному site-блоку EvidenceRAG с тем же bind. Не затрагивать другие маршруты, VPN, DNS сервера и firewall.
5. Validate → graceful reload → действительная проверка HTTPS, health, frontend и demo. Старое имя оставить рабочим, чтобы не терять доступ к существующим сеансам: cookies привязаны к hostname и между именами не переносятся.
6. После успеха обновить основную ссылку в документации и handoff. Не утверждать, что короткий адрес настроен, пока внешняя проверка не пройдёт.

Официальный сервис: https://www.duckdns.org/ . SSLIP по собственной документации разрешает IP-встроенные имена; произвольное удаление IP из нынешнего имени не создаёт управляемую DNS-запись: https://nip.io/ .
