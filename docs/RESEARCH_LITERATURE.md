# Карта литературы

Проверка первичных страниц и доступного кода: 31.10.2026. Это предварительный обзор, а не систематический обзор всего поля. Численные результаты авторов не воспроизводились. Объём GPU-памяти, где не измерен, не угадывается.

| Работа и первичный источник | Что установлено по доступному материалу | Код, ресурсы и отличие от текущего прототипа |
|---|---|---|
| [Sufficient Context, 2025](https://research.google/pubs/sufficient-context-a-new-lens-on-retrieval-augmented-generation-systems/) | Выделяет достаточность контекста отдельно от корректности генератора; изучает отказы. | [Авторский репозиторий с prompts](https://github.com/hljoren/sufficientcontext). LLM-оценщик требует инференса/API; наш лексический охват не является его заменой. |
| [Adaptive Retrieval Without Self-Knowledge?, ACL 2025](https://aclanthology.org/2025.acl-long.319/) | Сравнение адаптивных подходов и оценок неопределённости с учётом эффективности. | [AdaRAGUE](https://github.com/s-nlp/AdaRAGUE), MIT; официальный стенд использует модели и Wikipedia/Elasticsearch. Мы измеряем только CPU-поиск; сравнение результатов между такими стендами некорректно. |
| [S2G-RAG, ACL 2026](https://aclanthology.org/2026.acl-long.1185/) | Явный судья достаточности и структурированных пробелов управляет итерациями; контекст формируется на уровне предложений. | [Официальный код](https://github.com/nianaaa/S2G-RAG), прочитаны README, requirements и launcher. Есть обучение/инференс на CUDA и LoRA; точный необходимый VRAM не измерен. Наш контроллер без обученного судьи не является S2G-RAG. План запуска в S2G_BASELINE.md. |
| [RINSE, 2026](https://arxiv.org/abs/2609.37469) | Комбинирует покрытие частей вопроса, наличие ответа во фрагменте и совместную оценку небольшой моделью; отдельно рассматривает поверхностные утечки меток. | HTML доступен. Код в этом проходе не подтверждён. Авторы используют локальный GPU; лексическое совпадение нашего прототипа не эквивалентно их оценке. |
| [Conflict-Aware RAG, WWW 2026](https://doi.org/10.1145/3774904.3792289) | ConScore сравнивает вероятности генерации по разным источникам и направляет SFT/DPO и reranking. | DOI напрямую дал 403; аннотация доступна через индекс первичной страницы ACM. Полный текст и официальный код не изучены. Нужны обучаемые модели; точные ресурсы не установлены. Это существенно сильнее наших сигналов key:value. |
| [Self-RAG](https://selfrag.github.io/) | Токены рефлексии управляют поиском и критикой генерации. | [Код](https://github.com/AkariAsai/self-rag); обученные модели требуют GPU для практичного инференса. У нас нет обучения и оценки смысловой поддержки. |
| [DRAGIN, ACL 2024](https://aclanthology.org/2024.acl-long.702/) | Динамический поиск по текущей потребности LLM. | [Код](https://github.com/bltnynk/dynamic_rag); требуется доступ к инференсу и поисковому корпусу. Наш запрос расширяется только по отсутствующим терминам. |
| [ALCE](https://github.com/princeton-nlp/ALCE) | Стенд для генерации с цитированием и оценки атрибуции. | Код MIT; генераторы и NLI-оценка требуют дополнительных моделей/API. Наличие действительного ID ещё не доказывает поддержку утверждения; наш адаптер разрешает только дословные выдержки. |
| [VersionRAG, 2025](https://arxiv.org/abs/2510.08109) | Граф версий, изменений и маршрутизация по намерению запроса; версионное QA уже исследовалось. | Аннотация доступна; официальный код и требования к оборудованию в этом проходе не подтверждены. Наш SQLite-реестр и фильтры значительно проще графового метода. |
| [TimelyRAG, 2026](https://arxiv.org/abs/2609.11572) | Семантическое и временное ранжирование для документов с перекрывающимися поправками. | [Официальный код](https://github.com/kaist-dmlab/TimelyRAG); README указывает PyTorch/GPU. Лицензия для распространения набора отдельно не установлена. Наш max(date) применим только к полным снимкам. |

Простое объединение достаточности, конфликтов и версий нельзя объявлять новым методом. Особенно близки S2G-RAG, VersionRAG и TimelyRAG. Возможный предмет будущей работы — измеримый компромисс между сохранением версионной неоднозначности, отказом и стоимостью контекста. Новизна не подтверждена.
