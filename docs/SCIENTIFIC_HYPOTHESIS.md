# Проверяемая гипотеза

Рабочая тема: «Метод адаптивного формирования доказательного контекста RAG с учётом версионных противоречий и достаточности источников». Тема предложена для обсуждения с Михалёвым; научное утверждение пока не доказано и не утверждено руководителем.

H1: при одинаковом бюджете фрагментов явное извлечение сопоставимых редакций уменьшает долю неправильного выбора версии на независимом наборе версионных документов, сохраняя полноту релевантных свидетельств.

H2: явный отказ при неразрешённой применимости уменьшает неподкреплённые ответы, но снижает покрытие ответами; оценивать обе величины совместно. H3: при одинаковом качестве отказов адаптивная остановка уменьшает контекст или задержку.

Прототип проверяет инженерную осуществимость без GPU. Он использует лексические пробелы и точные различия подписанных полей; не выполняет смысловую оценку. Нельзя экстраполировать его результаты на свободные вопросы и произвольные документы.

Сравнение run-001 не выявляет превосходства предложенной стратегии: recall одинаковый, версия-ориентированная стратегия добавляет текст, а доля ложных отказов равна 1 на достаточных test-вопросах. Гипотеза остаётся открытой. Для содержательного эксперимента нужны независимые корпуса, сильные baseline, семантическая разметка и оценка применимости отдельных положений.
