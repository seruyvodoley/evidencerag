# Следующие шаги

1. Публикация завершена на release-005: osnovanie.duckdns.org, HTTPS и E2E проверены. Наблюдать pilot; при необходимости подключить собственный домен второго уровня.
2. Подготовить независимые реальные корпуса с временными изменениями и несколько независимых документных семейств. Описать критерии включения и двойную экспертную разметку достаточности, конфликта и применимости дат.
3. Подключить независимый семантический оценщик и answerer за явным feature flag, сохраняя полный отказ генерации при неопределённых доказательствах. Определить protocol selective risk/coverage до выбора порогов.
4. Воспроизвести S2G-RAG и другие доступные сильные baseline на подходящем отдельном GPU-стенде, фиксируя commit, версии, лицензии и compute budget. Сравнивать на одних данных и метриках.
5. После набора независимых кластеров добавить cluster bootstrap или подходящую иерархическую оценку, power/precision planning и отчёт доверительных интервалов. Трёх синтетических кластеров из run-004 для этого недостаточно.
6. Перед публичным LLM: постоянный бюджетный ledger, тарифы/провайдерские hard caps, тесты prompt injection и информированное согласие. Не включать LLM только ради свободного текста.
7. Улучшить мобильную библиотеку при большом количестве документов, локализацию, редактирование метаданных после загрузки, точные anchors/координаты PDF, отдельные лимиты диска с FTS overhead.
8. Позже — опциональные локальные embeddings на другом сервере; OCR отдельно по подтверждённой потребности. Не ставить тяжёлые модели на VPN-VPS.
