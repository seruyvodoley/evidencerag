# Следующие шаги

1. Завершить публикацию только после согласования отдельного HTTPS-hostname и добавления маршрута в общий Caddy; затем внешние smoke-тесты и повторная read-only проверка TunnelDeck.
2. Расширить эталонную разметку датированных вопросов и независимых семейств, добавить двойную смысловую разметку и семейный bootstrap. Текущих 63 fixtures недостаточно для статьи.
3. Воспроизвести S2G-RAG на отдельном GPU-стенде, зафиксировав commit и лицензии. Добавить VersionRAG/TimelyRAG, если доступны воспроизводимые исходники и ресурсы.
4. Добавить независимый оценщик поддержки, семантическую достаточность и оценку отказов при фиксированном answer coverage. Сейчас система в основном показывает фрагменты.
5. Перед публичным LLM: постоянный бюджетный ledger, тарифы/провайдерские hard caps, тесты prompt injection и информированное согласие. Не включать LLM только ради свободного текста.
6. Улучшить мобильную библиотеку при большом количестве документов, локализацию, редактирование метаданных после загрузки, точные anchors/координаты PDF, отдельные лимиты диска с FTS overhead.
7. Позже — опциональные локальные embeddings на другом сервере; OCR отдельно по подтверждённой потребности. Не ставить тяжёлые модели на VPN-VPS.
