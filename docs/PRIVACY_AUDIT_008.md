# Аудит приватности браузерной версии — этап 008

## Наблюдаемое поведение

Browser implementation обрабатывает документы в Pyodide Worker и сохраняет рабочее пространство в SQLite WASM/OPFS; указатель пространства расположен в IndexedDB. В отчётах Stage 007 (`docs/BROWSER_PRIVACY_AUDIT.md`, `experiments/browser-migration-007/`) синтетический marker не покинул origin; OPFS harness проверял перезапуск worker и удаление строк. Stage 008 Playwright проверяет только origin requests, `/api` calls, marker leakage, cookies/storage и WASM MIME при выполнении соответствующего acceptance сценария; последний локальный офлайн прогон остановился на выборе коллекции, поэтому не заявляется как пройденный.

У GitVerse static host есть сетевой доступ и он видит IP-адрес и HTTP metadata посетителя. Это не равно локальному хранению браузера. Отдельная страница cookie информирует о first-party техническом поведении; аналитических/рекламных скриптов приложение не добавляет. В актуальной сборке мета CSP задаёт `default-src 'self'`, локальные worker/wasm и ограниченные `connect-src`, `object-src 'none'`, `base-uri 'self'`, `form-action 'self'`.

## Ограничения

- Проверка сети не является юридическим заключением о соблюдении всех требований РФ/ЕС. Операторские реквизиты, правовое основание, retention на стороне GitVerse и трансграничная обработка требуют отдельной оценки оператора/юриста.
- CSP через meta не может установить `frame-ancestors` и часть response-only директив. На публичных ответах GitVerse в прошлой проверке отсутствовали CSP response header, HSTS, X-Content-Type-Options, Referrer-Policy и X-Frame-Options; статический host не предоставляет в проекте управляемую настройку response headers. Проверьте актуальные headers после Stage 008 публикации.
- OPFS/IndexedDB находятся в браузерном профиле пользователя; браузер/пользователь может очистить данные, а квоты отличаются. Экспорт — единственный переносимый backup.
- Удаление локального пространства удаляет строки БД штатным кодом, но не является криптографической гарантией стирания flash/cache/backup.
- Не тестировались полный XSS/fuzzing аудит сторонних зависимостей, злонамеренные архивы на все лимиты, профили браузерного приватного режима или изоляция между всеми возможными браузерными origin.
