# Построение и проверка ответов — этап 009

## Результат

Browser-local исследовательский режим теперь имеет два контролируемых пути:

- существующее явно авторское правило для заранее описанного демо-вопроса выдаёт только verbatim claim;
- `StructuredClaimEvaluator` + `StructuredFactAnswerGenerator` составляют короткую строку из извлечённых атрибутов, когда все запрошенные характеристики подтверждены применимыми фрагментами.

Каждый structured claim содержит атрибут, значение, исходную цитату, stable evidence ID, группу/версию и дату действия. Answer response включает `text`, `claims`, `citations`, `applicability`, `conflicts`, `missing_information`, `verification_status` через trace schema.

## Механическая проверка

Перед показом ответа проверяется, что:

1. ID цитаты есть среди выбранных фрагментов.
2. Цитата побайтно равна тексту исходного chunk, включённого в ответ.
3. Тот же явный извлекатель на этой цитате снова находит указанный атрибут и значение.
4. У факта есть метаданная дата применимости.
5. Сводная строка в точности собрана из проверенных claim-строк.

Это сильнее проверки наличия одной ссылки, но это не проверка семантического entailment. Извлекатель и verifier используют один и тот же детерминированный код, поэтому их ошибки коррелируют. Цитата может быть подлинной, но правило неверно интерпретировать контекст/отрицание/условие.

Если любое условие не выполнено, answerer отказывает; если assessment `uncertain`, `insufficient` или `conflicting`, генератор вообще не вызывается. Свободный LLM answerer отсутствует, сетевые модели не вызываются.

## Интерфейс

В режиме EvidenceRAG ответ показывается перед списком найденных источников. У каждого факта своя дата действия и кнопка открытия первоисточника; недостающие характеристики выводятся отдельно. Неопределённость и конфликт не маскируются уверенным текстом. На узком экране список фактов складывается вертикально.

Существующая lexical-страница сохраняет прежний отдельный формальный вывод. Основные ограничения метода описаны в `/method`; текст не называет lexical match entailment.
