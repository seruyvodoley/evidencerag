# Итоговый отчёт: исследовательская итерация и публикация

Дата: 31.10.2026. «Основание» доступно по [osnovanie.duckdns.org](https://osnovanie.duckdns.org), production release `20261031-005`.

## Реализовано

1. Проверены исходники retrieval, датасеты, прежние offline-прогоны и исследовательские предпосылки. Аудит нашёл ошибку `False Abstention=1.0`: без answerer эта метрика неприменима. Также датированные изменения значений ошибочно попадали в same-edition conflict, а одна прежняя абляция фактически не выключала версионность.
2. В retrieval-коде разделены изменения между известными редакциями, буквальные несовпадения поля внутри одной редакции и неизвестная применимость. Сигналы поля ограничены вопросом; добавлены стабильные evidence IDs, provenance, bounded traces и отдельные адаптивные конфигурации. Подробный разбор — [технический аудит](AUDIT_20261031.md).
3. Offline runner теперь имеет общую схему fixed-k, fixed-10 sensitivity, score-gap adaptive-k, retrieval без judge, EvidenceRAG и три абляции. Общий лимит на одну конфигурацию: 3 итерации, 20 фрагментов, 500 мс. Независимого генератора и judge нет; показатели качества ответа оставлены `null`.
4. Обновлены пользовательские подписи для истории редакций и конфликтов. Сохранены существующий визуальный язык, навигация и favicon; страница метода честно описывает BM25 score-gap как lexical heuristic. Использованы загруженные frontend-design и web-design-guidelines навыки.

## Эксперимент

`experiments/run-004/` зафиксирован после чистого commit `8e3e704a68d9abc7f99c29927208d9c071366dad`; данные и код имеют SHA-256, `git_dirty_tracked_before_run=false`. Прогон охватывает 21 синтетический test-вопрос в 3 кластерах и 8 конфигурациях.

- Все конфигурации покрыли размеченные обязательные строки; у основных методов recall обязательных источников равен 1.0.
- Score-gap adaptive-k получил evidence precision 0.702 и использовал в среднем 2.095 фрагмента; прототип EvidenceRAG — precision 0.494 и 2.810 фрагмента. На этих fixtures adaptive-k оказался экономнее по контексту. Это не оценка преимуществ на реальных данных.
- Без версионности same-edition conflict F1 снизился до 0.889, а F1 обнаружения редакционных изменений — до 0. Без буквальных сигналов полей оба сигнала пропускаются.
- Answer correctness, semantic sufficiency, false abstention, unsupported answer, faithfulness и API cost — `null`: соответствующих компонентов нет. Только три test-кластера — недостаточно для статистического вывода; доверительные интервалы и p-values не заявляются.

Полная таблица и метод расчёта находятся в [EVALUATION.md](EVALUATION.md) и [run-004/REPORT.md](../experiments/run-004/REPORT.md). Ранее сохранённые run-001–003 не перезаписаны; их прежний False Abstention недействителен.

## Проверки и production

- Python: 39 тестов прошли; Svelte check: 0 ошибок/предупреждений; production build прошёл.
- Публичные Playwright: 8/8 сценариев всего, по 4 в desktop и mobile Chromium; серверный smoke: 17/17. Отчёты: `experiments/e2e-release-005.json`, `experiments/vps-smoke-release-005.json`.
- Публичный health сообщает `lexical-controller-v2`; HTTPS, demo, search, upload/delete, compare, ссылки, прямые URL и история браузера работают.
- Установлен только собственный сервис: `/opt/evidencerag/releases/20261031-005`, localhost:8077, отдельный systemd unit, CPU 60%, память до 640 MiB. Существующий Caddy остался запущен и не менялся. Схема БД неизменна, миграций нет.
- После публикации VPN/Xray InvocationID и fingerprints интерфейсов, route/rule, firewall и Docker networks совпали с предыдущим сохранённым post-publication snapshot. Публичный SSH timeout обходился ранее существующим проверенным private SSH path с обязательной проверкой host key; ключи и секреты не копировались.

## Ограничения

Датасет авторский и синтетический: 63 сценария, 3 test-кластера. Нет независимой разметки, семантического judge, генерации свободных ответов, OCR, embeddings или сильных воспроизведённых baseline. Обзор публикаций доступен в [RESEARCH_LITERATURE.md](RESEARCH_LITERATURE.md): Sufficient Context, Adaptive-k, S2G-RAG, VersionRAG, TimelyRAG и близкие методы уже покрывают существенные части первоначальной идеи. Новизна и преимущество не установлены.

Проект — публичный исследовательский прототип. До научных выводов требуются независимый real-world корпус, двойная экспертная разметка, семантическая оценка достаточности, воспроизводимые сильные baseline и статистика на независимых группах.
