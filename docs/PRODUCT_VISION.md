# Назначение

«Основание» помогает обычному пользователю проверить документы: найти исходную формулировку, увидеть редакцию и понять ограничения ответа. Техническое имя — EvidenceRAG. Это самостоятельный проект, не копия FlySwarm.

Основной сценарий: открыть демонабор → задать вопрос → увидеть реальные найденные фрагменты → выбрать редакцию/дату → открыть точную цитату → сравнить редакции. Для личных документов тот же сценарий начинается с загрузки в приватное временное пространство.

Первый релиз ориентирован на инструкции, правила и техническую документацию с текстовым слоем. Не обещает юридического заключения, распознавания сканов или автоматической смысловой проверки. Аудитория не ограничена студентами. Публичная галерея содержит только авторские вымышленные документы CC0.

Работающие функции важнее декоративного лендинга. Критерий доверия — возможность проверить первоисточник и отсутствие неподкреплённых обещаний. Публичный запуск требует безопасного маршрута HTTPS; локальный интерфейс и localhost-экземпляр не равнозначны публичному релизу.
