# API «Лист»

Редакция 1.0. Действует с 2024-09-01.

## Запросы

Лимит запросов: 60 в минуту
Максимальный размер страницы: 50 записей
Формат ответа: JSON
После превышения лимита сервер отвечает HTTP 429. Повторять запрос рекомендуется после Retry-After.

## Авторизация

Способ авторизации: заголовок X-API-Key
Срок действия ключа: 30 дней
Не передавайте ключ в параметрах URL. Ключ создаётся в личном кабинете и показывается один раз.

## Методы

Метод списка: GET /v1/leaves
Удаление записи: DELETE /v1/leaves/{id}
Поле времени: created_at
Фильтрация доступна по дате создания. Удаление необратимо. Гарантия доступности в этом документе не определена.
