# API «Лист»

Редакция 2.0. Действует с 2025-10-01.

## Запросы

Лимит запросов: 120 в минуту
Максимальный размер страницы: 100 записей
Формат ответа: JSON
При HTTP 429 учитывайте Retry-After. Клиенты должны ограничивать число повторных запросов.

## Авторизация

Способ авторизации: заголовок Authorization Bearer
Срок действия ключа: 90 дней
Старый X-API-Key больше не поддерживается. Ключи храните на сервере, вне клиентского приложения.

## Методы

Метод списка: GET /v2/leaves
Удаление записи: DELETE /v2/leaves/{id}
Поле времени: createdAt
Новая пагинация использует курсоры. Имена полей изменились. Условия SLA в этой редакции не заданы.
