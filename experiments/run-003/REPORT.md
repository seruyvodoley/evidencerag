# Синтетическая проверка, не научное доказательство

Срез: test; 21 случаев на стратегию.

| Стратегия | Recall источников | F1 конфликтов | Ложный отказ | Средний контекст, символы |
|---|---:|---:|---:|---:|
| fixed5 | 1.000 | 0.909 | 1.000 | 292.048 |
| fixed10 | 1.000 | 0.909 | 1.000 | 319.714 |
| adaptive | 1.000 | 0.909 | 1.000 | 279.190 |
| versioned | 1.000 | 0.909 | 1.000 | 304.429 |
| without_sufficiency | 1.000 | 0.909 | 1.000 | 304.429 |
| without_versions | 1.000 | 0.909 | 1.000 | 279.190 |
| without_conflicts | 1.000 | 0.000 | 1.000 | 304.429 |
| without_adaptation | 1.000 | 0.909 | 1.000 | 304.429 |

Свободная генерация отключена. Faithfulness не измерена: независимого оценщика нет. Нулевое число неподтверждённых ответов при полном отказе от генерации не означает высокое качество ответов. Большинство достаточных вопросов получает отказ. Это ограничение текущей политики.

Абляция without_sufficiency отключает только лексическое условие остановки; without_adaptation ограничивает число итераций. Они не являются абляциями семантических моделей. Слишком малый корпус часто не различает стратегии. Wilson CI игнорирует зависимость вопросов одной семьи и приведён только как иллюстрация неопределённости; для статьи нужны семейный bootstrap и независимые документы.
